# Bachelorarbeit-Magnetika-Laborversuch-Neuentwicklung

Es handelt sich um eine Messporgramm für die 
LVA 366.110: LU Materialien der Elektrotechnik

Die Bachelorarbeit beschäftigt sich mit der Messung von Hysteresekurven. 
Dazu wird die alte LabView Version umgestellt auf das open source verfügbare Python als Programmiersprache.
Zur Messung wird das digitale Osziloskop Analog Discovery 3 von Digilent verwendet.

Das Messprogramm stellt die Verbindung zum AD3 her und verwendet beide Oszi Kanäle. Die Messdaten werden 
in CSV-Dateien gespeichert. Die Steuerung der Messungen erfolgt über das erstellte GUI.
Das GUI wird verwendet um den Studierenden die Möglichkeit zu bieten live die Messung als Plot zu verfolgen.
